# Session 28, 2026-09-12: Stripe webhook secret on crowlr2, proof by targeted resend

Input: wire the Stripe webhook of the activation server (api.compr.ch, pm2 `contextengine-api`,
port 8010) and prove it. The agent was read-only on the server for the whole session
(agent-on-server tier 1); every write on the box was Yan's hands, from prepared commands.
The stated proof, "resend the 2026-09-10 `customer.subscription.deleted` event and get a 200",
turned out to be impossible by construction (section 2).

## 2. Findings

- The 2026-09-10 cancellation is a **live** invoc.me subscription ("planning" plan,
  120 CHF/month, metadata `project_slug: invocme`), cancelled on request at 10:28Z. The
  ContextEngine endpoint exists in **test mode only**, and the server holds an `sk_test_` key.
  Stripe never delivers across modes, so that event could not be the proof, and even
  delivered it would have answered 200 with `Deactivated: false` (no mapping row).
- `STRIPE_SECRET_KEY` and `STRIPE_WEBHOOK_SECRET` sit on ONE line of the ecosystem file. A
  first edit inserted a duplicate key with `sed i\`, which lost to the original; the fix was an
  in-place value replace. The file already held a webhook secret since 2026-02-23; it had never
  been exercised on crowlr2 (only one webhook call in the log since 2026-08-31, unsigned).
- Three test licences from 2026-03-27 in `stripe_mapping` prove the flow worked before the
  Gandi to crowlr2 migration.
- A copy of Yan's Mac private SSH key (`id_ed25519`, fingerprint identical to the key in
  `authorized_keys`, unencrypted, mode 600) sits in the web directory. Not shipped by the repo
  (no such file in `server/`), origin unknown, dated 2025-03-01. Deletion is Yan's hands,
  steps given in chat; the deploy rsync now excludes `id_*` (section 3).
- `server/.DS_Store` exists locally and the rsync had no exclude for it, so it came back on
  every deploy.
- The community-rules rate limiter logged `ERR_ERL_KEY_GEN_IPV6` at every boot
  (express-rate-limit 8.2.1, custom keyGenerator falling back to raw `req.ip`). Non-fatal.
- The server runs a test-mode key: the ContextEngine checkout cannot take real money today.
- Stripe CLI: `stripe events retrieve --live` from a non-interactive shell blocked on the macOS
  keychain prompt for `default.live_mode_api_key` and had to be killed; `stripe events list
  --live` returns the full objects and served the same purpose.
